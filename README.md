# نظام تحويلات مالية

هذا المشروع هو موقع ويب عربي بالكامل يدعم الاتجاه من اليمين لليسار (RTL) ويستخدم Tailwind CSS لبناء واجهة حديثة. يتضمن:

- نموذج إدخال تحويل مالي
- لوحة تحكم إحصائية مباشرة
- جدول بيانات مع بحث وتصفية
- تصدير CSV و Excel
- ربط Firestore لحفظ البيانات في الوقت الفعلي

## التشغيل محلياً

1. استبدل القيم في ملف `firebase-config.js` ببيانات مشروع Firebase الخاص بك.
2. شغّل الخادم المحلي:

```bash
python -m http.server 8000
```

3. افتح المتصفح على:

```text
http://localhost:8000
```

## إعداد Firebase

1. أنشئ مشروع Firebase جديداً في [Firebase Console](https://console.firebase.google.com/).
2. أضف تطبيق ويب ثم انسخ إعدادات SDK إلى `firebase-config.js`.
3. في Firestore Database، أنشئ مجموعة باسم `transactions`.
4. تأكد أن قاعدة البيانات تملك صلاحية القراءة والكتابة للمشروع.

> ملاحظة: إذا لم يتم تعيين بيانات Firebase، سيعمل المشروع في وضع العرض التجريبي.
